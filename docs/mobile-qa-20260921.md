# Mobile Layout Audit

Target: https://archiiive99.github.io/PAVER/ (`gh-pages`).
Baseline: `ef8fc37a`. The profile website is a separate repository and was not modified.

## Changes

- Phone-specific layout in `mobile.css` at widths up to 700px and short touch-screen landscape viewports; desktop layout retained.
- Smaller content padding and 6-10px corner radii for media, panels and multi-row controls.
- Fixed phone typography, intact author names, full-width scene selectors and 44px primary touch targets.
- Playback controls use a stable seek row and a separate speed row.
- All generated SVG charts use a scrollable host, including nested plots previously missed by the CSS selector. Data and axis labels are retained, not cropped out or removed.
- Navigation closes on outside touch and Escape, and resets its accessible label after selection.
- Two-finger zoom on the paired 3D canvases; touch cancellation clears drag state.
- Video seek cancellation removes its temporary pointer listeners.
- On phones, Back to top lives at the document end instead of covering video controls.

## Content Invariant

The HTML body, data.js, dims.js, supp.js, webviz.js and media assets are unchanged.
No paper text, authors, metric values, scenes or illustrations were replaced.
The HTML diff only adds the responsive stylesheet and changes script cache versions.

## Reproduction

Use a static server supporting HTTP byte ranges, which are needed for video seeking:

```sh
npx http-server . -p 53798 -a 127.0.0.1 -c-1
PLAYWRIGHT_MODULE=/path/to/playwright/index.mjs node tools/mobile_qa.mjs
```

`PAGE_URL` and `QA_OUTPUT` can override the tested deployment and screenshot directory.
The script covers 320x740, 390x844 light/dark, 430x932, 844x390 landscape,
768x1024, and 1440x1000. Each run captures all 13 sections and checks document
overflow, chart scrolling, mobile navigation, playback, seek, chart/table switching,
theme switching and uncaught JavaScript exceptions. The 390px run also checks
nonblank canvas pixels and sends two-contact touch events to verify zoom changes
the rendered canvas and releases drag state.

Screenshots and machine-readable results are saved outside the source tree under
`/tmp/paver-mobile-final`. Chromium mobile emulation is not a physical-device test.
WebKit was downloaded but could not launch because this host lacks its GTK/GStreamer
runtime dependencies; no iOS Safari claim is made.
